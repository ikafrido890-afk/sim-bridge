2. APK KAISE BANAYE BINA LAPTOP KE (GitHub se):

   b) Is ZIP ko upload kar do
   c) GitHub Actions automatically APK bana dega (maine .github/workflows/build.yml daal diya hai)
   d) 5 minute me Actions tab me APK ready mil jayega download ke liye
